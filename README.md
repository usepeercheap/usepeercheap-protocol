## Overview

PEER is a holder-to-holder board for Solana tokens. It pairs a live view of the busiest tokens on the chain with a simple promise: size should move between wallets without dragging a chart along with it.

The site is a static bundle. There is no backend, no key, and no wallet connection on the page itself.

## Features

- Live market board of the ten most active Solana tokens, refreshed every minute and paused while the tab is hidden
- A pinned first row reserved for the PEER token, which activates the moment a contract address is published
- Scrolling ticker fed from the same live data
- Copy-to-clipboard on every token address
- Reduced-motion support across every animation
